### 现状（2026-11-09 更新）

**12.1 / 12.2 角色与敌人精灵 —— 已完成。**

- 32 张横条全部换成 AI 重制版（Qwen-Image2.1 图像编辑，双参考图：`image_1` = 1024 图标做风格锚，`image_2` = MVP 旧精灵做造型锚）
- 格子 **56（玩家/小怪）/ 128（Boss）**。依据是代码实际显示尺寸：`player.gd:176` 与 `enemy_base.gd:319` 都是 `_present_sprite(56.0)`，`vampire_lord.gd:273` 是 `128.0 * size_mult`；按 GDD 附录 C「以代码为准」。这样图素与屏幕像素 **1:1**，不再有 48→56 的 1.167 倍非整数拉伸
- 播放链路不变：`sprite_sheet.gd` 按 `宽 ÷ 高` 推帧数，8fps 循环

> 资产状态、来源、验收数据、回退方式见 [asset-status.md](asset-status.md)（单一事实来源，先看这份）

玩家四张动作图**已接入**，与原有程序特效叠加而不是替换：

- `player_attack` ← `apply_recoil()` 时播一次，与开火挤压同时发生（挤压负责后坐力，动作帧负责姿态）
- `player_hurt` ← 扣血时播一次，闪红照旧
- `player_shield` ← `_grant_shield()` 时播一次；持续脉冲仍由 `_shield_aura` 程序光环负责
- `player_death` ← `_die()` 里按帧推进 death 横条（physics 已停，改用 tween），**去掉了原来叠在外面的 modulate 淡出**，因为横条本身末帧就是全透明，叠两层会双重变淡

单测 `tools/_test_player_actions.tscn` 覆盖了四条的切换与回落；跑完 0.8s 回到 `idle`。

### 17.9 Roguelite 决策层 ✅ 已完成（2026-11-08 第四轮）

这一批解决的是同一个问题：**玩家在局内几乎没有"做选择"的机会**。

每一局都有"花资源做取舍"的时刻。

| 项 | 状态 | 实现要点 |
|---|---|---|
| 放逐 Banish | ✅ | 每局 3 次，进模式后点卡把它从**本局**选池永久移除；自带一次免费刷新，不吃重抽次数；只影响三选一池，商店照旧 |
| 深渊契约 | ✅ | 休息房改血之祭坛二选一：安息回 50%，或卖本层 20% 生命上限换本层敌人 +20% 数量 / 掉落 +30%，层末归还。同层限一次，残血禁选 |
| DPS 软挂钩 | ✅ | `实际 DPS / 该等级期望 DPS` 的比值开 0.35 次方，夹在 0.85~1.55，每波 lerp 靠拢。**只做软修正**，超模 2 倍也只硬 27% |

**五个实现取舍**（详见 GDD §16.15.3）：

1. 流血走 `dot_damage()` 不走 `take_damage()` —— 后者每次闪白 + 冻帧，每 0.5 秒闪一次会把"在流血"和"刚被打中"混淆。代价是绕过子类覆写，所以**护甲（石像鬼）/ 登场无敌（Boss）用 `get()` 鸭子类型单独补上**。
2. 状态 tick 放 `_process` 不放 `_physics_process` —— 有一半敌人覆写了物理帧，基类钩子对它们不执行。当前**没有任何子类覆写 `_process`**，这条约束要守住。
3. 急速从"await 还原本速"改成"记剩余时间 + 统一刷新"，否则和减速叠加时两个协程互相覆盖成永久变慢/变快。多来源减速**取最强**而非相乘（相乘 0.7×0.7=0.49 等于控到死）。
4. 弱流血既不叠层也不续时间 —— 否则高频小弹能把十字弩的高伤流血永久续着。
5. 同一敌人 0.3 秒内只判一次 —— 高攻速下不设冷却，流血/减速会永久满覆盖。

**顺带修的测试脆弱点**：`phase17_test` / `feedback_v2_test` 隐式依赖"存档里选的是猎人"（初始手枪），

以后新测试一律不许依赖存档。

**三个实现取舍**：

1. 岔路不写进 `_room_plan`。计划表仍是 combat/shop/treasure/rest/boss，`consume_room()` 只有玩家选了事件房才返回 mutation/fog/mirror。旧的结构验算不用改口径。
2. 每日赏金乘在 `loot_bonus_mult` 上，不写进契约会整段覆盖的 `loot_mult`。迷雾是 `room_loot_mult`，换房归 1。深渊仍在最外层。四段谁被清掉都不连坐。
3. 迷雾用世界坐标画环，不用屏幕着色器。`FRAGCOORD` 的原点在不同版本里上下相反，洞会对不准人。
