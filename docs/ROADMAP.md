## ✅ Phase 11: 战斗手感、内容扩展与性能优化（已完成）

### 11.1 战斗手感

- 敌人受击硬直与击退
- 玩家受击击退
- 受击/死亡屏幕震动
- 命中粒子反馈

### 11.2 武器与被动道具

- 新增武器：十字弩、圣光魔杖
- 新增被动：吸血獠牙、疾风靴、幸运四叶草（暴击）
- 武器进化视觉强化已覆盖新武器

### 11.3 Boss 机制

- 吸血鬼领主新增第三阶段“绝望模式”（25% 血量）
- 新增“新星爆发”双环弹幕攻击
- 攻击前 Telegraph 与警告特效
- 阶段转换/死亡屏幕震动

### 11.4 UI 打磨

- 角色选择卡片悬停/选中/锁定视觉
- 暂停菜单与结算界面按钮纹理
- HUD 低血量红闪警告

### 11.5 性能优化

- 新增 `ObjectPool` 自动加载单例
- 子弹、经验宝石对象池复用
- 延迟归还避免物理回调冲突

## 🔴 Phase 12: 美术资源替换

### 现状
当前所有精灵图使用程序化生成的彩色方块，视觉效果较差。

### 目标
替换为像素美术资源，提升游戏视觉质量。

### 具体任务

#### 12.1 角色精灵 (高优先级)

| 资源 | 尺寸 | 动画帧数 | 描述 |
|------|------|----------|------|
| 玩家待机 | 32x32 | 4帧 | 呼吸/浮动效果 |
| 玩家移动 | 32x32 | 6帧 | 跑步动画 |
| 玩家攻击 | 32x32 | 4帧 | 射击动作 |
| 玩家受伤 | 32x32 | 2帧 | 受伤反馈 |
| 玩家死亡 | 32x32 | 6帧 | 死亡动画 |

#### 12.2 敌人精灵 (高优先级)

**基础敌人**:
- 🦇 蝙蝠 - 24x24，4帧飞行
- 🧟 僵尸 - 36x36，6帧行走
- 🐺 狼人 - 40x40，待机+冲锋
- 🧛 吸血鬼 - 32x32，待机+移动
- 💀 骷髅射手 - 32x32，待机+射击

**Boss**:
- 👹 吸血鬼领主 - 64x64，6组动画（待机、弹幕、召唤、冲刺、狂暴、死亡）

#### 12.3 UI 元素 (高优先级)

- 按钮（正常/悬停/按下状态）
- 血条、经验条
- 升级卡片
- 武器/被动道具图标

#### 12.4 背景与环境 (中优先级)

- 房间背景图
- Tilemap 瓦片
- 环境装饰（火炬、窗户、棺材等）

#### 12.5 特效 (中优先级)

- 受击粒子效果
- 死亡爆炸效果
- 升级光环
- 拾取特效

## ✅ Phase 15: 关卡深度（部分完成）

### 15.1 多层地下城 ✅ 已完成

- 3 层结构：血月回廊 → 骸骨墓穴 → 血之王座
- 每层 6/7 间房，最后一间为 Boss 房（共 20 间、12 个战斗波次）
- 层内节奏固定：第 1 间必为战斗房，特殊房 1–2 个，防纯随机断节奏
- 层倍率叠加波次缩放（HP 1.0/1.22/1.5，伤害 1.0/1.18/1.4）
- 层通关奖励：回血 50% + 血晶 30/60/120
- 楼层横幅（层名 + 英文副标题 + 氛围提示）
- HUD 显示「第 N 层 · 层名 · X/Y」

实现位置：`scripts/map/dungeon_manager.gd`、`scripts/ui/floor_banner.gd`、`scripts/managers/main.gd`

验算工具：`tools/dungeon_test.gd`（结构校验 + TTK）、`tools/run_dungeon_smoke.gd`（三层全流程冒烟）

### 15.2 地图事件 ❌ 未开始

- 随机事件（陷阱/NPC/隐藏房间）
- 特殊房间机制深度（当前商店/宝箱/休息只是即时奖励）

### 15.3 多 Boss ✅ 已完成（形态变体）

- 三层 Boss 已实现：吸血鬼领主 / 血族亲王 / 血族女王
- 三者共用 `vampire_lord.tscn`，由 `boss_variant` 驱动数值、攻击参数、体型与光环色
- 后续若要机制完全不同的 Boss，需新建独立场景与脚本

### 15.4 每日挑战 ❌ 未开始

- 固定种子
- 特殊规则

### 17.0 本轮已完成（2026-11-08）

| 项 | 内容 | 验收 |
|---|---|---|
| 弹道可读性 | 新增 `scripts/core/projectile_visuals.gd`，程序化生成"亮芯 + 光晕"贴图，走加色混合；玩家 8 种武器 / 敌人投射物 / Boss 弹幕全部接入 | `tools/combat_visual_test.gd` 全部通过；子弹 16×6（原 6×6）、敌人弹 16（原 8×4） |
| 武器差异化配色 | 每把武器独立弹道颜色，混战时可分辨来源 | 同上（GDD 附录 D.1） |
| Boss 登场无敌 | 2.6s 无敌 + 碰撞关闭 + 血条 0→满 + 护盾消散；HUD 显示"登场中·无敌" | 测试中连续打 2 次 200 伤害血量不变，2.9s 后可正常掉血 |
| Boss 血条同步 bug | 补 `take_damage_with_knockback` 覆写——之前子弹走基类实现，掉血但血条不动 | 同上（扣血后血条同步刷新） |

### 17.1 P0 局内金币 + 商店房 ✅ 已完成（2026-11-08）

| 项 | 实现 |
|---|---|
| 金币掉落 | `enemy_base.silver_value`：普通怪 1 / 精英 5 / Boss 12，30px 内自动合并；`silver_coin.gd` 吸附拾取，12s 未拾自动收取 |
| HUD | 顶栏 💰 计数，`player.silver_changed` 驱动 |
| 商店 UI | `scripts/ui/room_shop.gd`：4 格货架 + 重抽（8/12/16）+ 锁定 + 离开，代码构建无 .tscn |
| 价格 | 武器 26-34 / 被动 20-26 / 消耗品 10-22（`scripts/core/item_catalog.gd`） |
| 规则 | 武器槽满只卖已拥有武器（重复购买＝升级）；进店回血 20%；直接结算不清空（局内货币，随局结束） |

**测试**：`tools/shop_test.gd`（21 项）、`tools/run_dungeon_smoke.gd`（商店弹出 → 关闭 → 传送门）

### 17.2 P0 升级三选一：重抽 / 跳过 ✅ 已完成（2026-11-08）

| 项 | 实现 |
|---|---|
| 免费重抽 | 每局 3 次（`GameConfig.REROLL_FREE_COUNT`），界面底部显示剩余次数 |
| 付费重抽 | 免费用完后 10 银币/次，钱不够按钮自动置灰 |
| 跳过 | +15 银币（`SKIP_SILVER_REWARD`），不直接给血晶 |
| 快捷键 | `R` 重抽、`Tab` 跳过（界面 `PROCESS_MODE_ALWAYS`，暂停时也能收输入） |
| 顺手修 | 重抽时旧卡未即时移除（6 张卡叠加）；连续升级丢选项（加 `_pending_upgrades` 队列） |

### 17.3 P1 进化改成事件 ✅ 已完成（2026-11-08）

| 武器 | 进化名 | 行为差异 |
|---|---|---|
| 手枪（+幸运四叶草） | 神圣双管 | 并排双发，横向覆盖 |
| 魔法书（+经验磁铁） | 大魔导书 | 8 方向环形弹幕，放弃瞄准 |
| 飞刀（+疾风靴） | 刀阵旋风 | 6 把刀环绕玩家持续绞杀（`orbit_blade.gd`） |

- 条件：武器满级 + 指定被动 Lv1 + 开宝箱（宝箱房是唯一入口，击杀数阈值已废弃）
- HUD 三态：不显示 / 灰字"还差 XXX" / 金字闪烁"宝箱可进化"
- 其余 8 把武器同样只认宝箱，仍走数值强化

### 17.4 P1 打击感三件套 ✅ 已完成（2026-11-08）

- 枪口闪光 60ms（加色锥形，每次开火一次）
- 命中冻帧 0.05s，仅冻受击者，Boss 免疫；**不用 `Engine.time_scale`**
- 玩家后坐 60px/s，0.1s 衰减，叠加但封顶（否则多武器会变成持续推人）

### 17.5 P2 Boss 地面标记 ✅ 已完成（2026-11-08）

- `vfx.spawn_ground_marker(pos, radius, color, duration)`：35% → 100% 生长，落点闪白淡出
- 冲刺：落点 82px 红圈 + **0.45s 前摇**（新增 `DASH_WINDUP`）
- 新星：本体 150px 紫圈 + **0.55s 前摇**（新增 `NOVA_WINDUP`）

**测试**：`tools/phase17_test.gd`（约 40 项断言），与 `combat_visual_test` / `shop_test` /
`run_dungeon_smoke` 一起作为回归门槛。

### 17.6 试玩反馈修正 ✅ 已完成（2026-11-08 第二轮）

| 反馈 | 改动 |
|---|---|
| 开火时人物轻微回退 | 后坐力从"真实速度"改为**纯视觉挤压**（6% / 0.08s），坐标零位移 |
| 护盾没有显式提醒 | 角色身上加镂空光环 + HUD 护盾条（充能 Ns / 已激活）+ 拾取即生效；删掉永不停止的蓝色 modulate 循环 |
| 武器 / 技能没有等级提示 | 三选一卡片加 `NEW`/`升级`/`属性` 角标 + `Lv.N → Lv.N+1` 等级行 + 数值对比；HUD 左侧常驻武器/被动等级面板 |
| 满级武器仍出现在三选一 | 过滤满级项，避免 `Lv.5 → Lv.5` 废卡 |

**测试**：`tools/feedback_v2_test.gd`（47 项断言全绿）+ `tools/hud_shot.gd` 截图核对。

### 17.7 经验点可读性 ✅ 已完成（2026-11-08 第三轮）

用户反馈"经验点太小看不清"。原实现是 6×6 白方块缩到 0.6 倍（屏幕约 3.6px）。

| 项 | 实现 |
|---|---|
| 形状 | 程序化菱形宝石（`ProjectileVisuals.get_gem_texture()`）：菱形本体 + 中心高光 + 外圈柔光 + 加色混合 |
| 分档 | <8 XP 绿 14px / 8-19 蓝 19px / ≥20 金 26px（精英、法师、Boss） |
| 合并 | 30px 内的掉落并成一枚（值相加、档位跟着升），同屏小点数量大幅下降 |
| 呼吸 | 幅度 9%~16% 的轻微脉动；拾取时先 kill 呼吸 tween，避免两个 tween 抢 scale |

**测试**：`tools/xp_gem_test.gd`（29 项断言）+ `tools/gem_shot.gd` 截图核对。

### 17.8 精英词缀系统 ✅ 已完成（2026-11-08 第三轮）

把"再加一种敌人"换成"现有 8 种敌人随机长词缀"，详见 GDD §16.9。

| 词缀 | 行为 |
|---|---|
| 血盾 | 开场一层盾（直接计入 max_hp，任何伤害路径都先吃盾），破盾有破碎演出 |
| 冲锋 | 0.6s 前摇 + 地面预警圈 → 3.2 倍速突进 → 0.55s 收招 |
| 裂变 | 死亡时裂成 2 只小的（禁止继承词缀，防无限裂变） |
| 急速 | 每 0.4s 给 150px 内敌人刷新 ×1.3 移速，持续 0.75s |

- 统一加成：血 ×1.55 / 伤 ×1.20 / 银币 ×4 / 经验 ×2 / 体型 ×1.22
- 出现概率：第 1/2/3 层 10% / 15% / 20%；Boss 与裂变体不参与
- 表现：红/蓝/紫/金镂空光环 + 头顶图标 + 出场扩散圈
- 顺带统一 `elite_vampire` 的私有词缀（原 enum SPEED/ARMOR/SPLIT 与 modulate 循环）

**测试**：`tools/elite_affix_test.gd`（45 项断言）。
