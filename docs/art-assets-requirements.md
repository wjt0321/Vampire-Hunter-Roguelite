## 🎮 一、角色精灵图 (Sprites)

文件都在 `assets/sprites/`，`TextureManager` 按「状态名 → 一张图」加载。屏幕上玩家和小怪最长边是 **56px**，Boss 是 **128px**（`player.gd` / `enemy_base.gd` / `vampire_lord.gd` 的 `_adjust_sprite_scale()`）。

### 1.1 现在实际长什么样

> **尺寸以代码为准，不是下面表格里的数字。**
> 所有横条一格 **56×56**，Boss 一格 **128×128**。屏幕上就是 1:1，图素与屏幕像素一一对应，没有重采样。
> 依据：`player.gd:176` 与 `enemy_base.gd:319` 都是 `_present_sprite(56.0)`，`vampire_lord.gd:273` 是 `128.0 * size_mult`。
> 完整状态、来源与验收数据见 [asset-status.md](asset-status.md)。

`SpriteSheet` 按 8 帧/秒循环，帧数 = 图宽 ÷ 图高，缩放按一格算。**所有一次性动作都已接上**：

- 玩家六个姿态都在用：`idle` / `run` 常驻切换；`attack` / `hurt` / `shield` 各播一次后自动回落到循环；`death` 播完停住不再动。
- 吸血鬼会换 `idle` / `run`，狼人会换 `idle` / `charge`，骷髅射手开火会播 `shoot`。
- Boss 会换 `idle`、`enraged`、`attack1`、`attack2`、`attack3`、`death`。
- 猎人和牧师塞西莉亚仍共用这一套玩家图，靠配色区分；没有第二套角色精灵。
- 精英词缀（盾、冲、裂、疾）是程序效果，不要为词缀各画一张静帧。

下面几张表里的「下一版」一列是**历史规划**，保留它是因为写清了每张图需要什么动作；实际规格以本节开头的说明为准。

### 1.2 静态帧发呆：怎么处理

发呆是因为屏幕上没有循环动作，不是因为图还不够大。再交一张更细的 1024 静帧，缩到 56px 之后还是一座雕像。

**先做一直停在屏幕上的姿态，一次性动作往后放。**

1. 交横条，不交方图。每一格是正方形，格与格紧贴，不留缝、不加框、透明底。帧数 = 图宽 ÷ 图高。玩家和小怪一格 **56×56**，Boss 一格 **128×128**。4 帧待机就是 224×56，不是 1024×1024。
2. 待机和移动必须是循环，至少 4 帧，按 **8 帧/秒** 播。待机只动披风、胸口或翅膀尖，身体不要整个人上下跳。移动要换重心，四格不能是同一张图挪了两个像素。
3. 受伤、射击、爆炸、死亡是播一次就回到循环的动作，可以后做。循环没做完之前，这些保持现在的单张即可。
4. 缩放按**一格**算，不按整张横条的宽度算。现在的 `_adjust_sprite_scale()` 用整图的长边去除 56。横条若仍这样算，4 格会被缩成一条 56px 宽的细条，每格只剩十几像素。播横条时除数用图高（正方形格子的边长）。
5. 一个状态仍是现在这个文件名、一张横条。`hframes` 由宽除以高得到，`vframes = 1`，`frame` 从 0 播到最后一格再回到 0。切状态时 `frame` 归零。朝向继续用 `flip_h`，不要画左右两套。
6. 玩家的 `run` 横条交了也不够：代码得在移动时换上它，停下换回 `idle`。只换文件、不写这次切换，跑起来仍是待机那一张。
7. 一次性动作播完必须回到循环。停在最后一帧会比现在更呆。
8. 横条还没交的时候，可以给待机加大约 1 像素、1.2 秒一来回的浮动，避免完全像贴图。这只是过渡，不能当成动画已经做完。

## 🚀 十一、AI美工工具推荐

### 11.1 像素艺术生成

| 工具 | 优势 | 适用场景 | 价格 |
|-----|------|---------|------|
| **Midjourney** | 高质量概念图 | 角色设计、背景 | $10/月 |
| **DALL-E 3** | 理解力强 | 快速原型、草图 | $20/月 |
| **Stable Diffusion** | 免费开源 | 批量生成、定制 | 免费 |
| **PixelLab** | 专为像素设计 | 精灵图、动画 | $15/月 |
| **Aseprite** | 专业像素软件 | 手动精修、动画 | $20一次性 |

### 11.2 推荐工作流

```
1. 概念设计: Midjourney/DALL-E → 生成角色概念图
2. 像素转换: PixelLab/Stable Diffusion → 转为像素风格
3. 精修动画: Aseprite → 手动调整、制作动画
4. UI设计: Figma + AI插件 → 界面设计
5. 特效生成: Stable Diffusion → 粒子特效
```

### 11.3 针对本游戏的推荐

**首选方案：Midjourney + Aseprite**
- 用 Midjourney 生成哥特风格角色概念图
- 在 Aseprite 中手动重绘为像素风格
- 保证风格统一和质量

**性价比方案：Stable Diffusion + Aseprite**
- 本地部署 SD，使用像素风格 LoRA
- 批量生成基础素材
- Aseprite 精修

**快速原型：PixelLab**
- 专为游戏像素艺术优化
- 内置角色模板和动画工具
- 适合快速出图
