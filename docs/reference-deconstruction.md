# 玩法扩充设计

> 文档状态：持续迭代的玩法案头。
>
> 本文只描述本项目的玩法，不引用外部项目、网页、代码或仓库，也不要求引入外部依赖。
>
> 「现有」表示当前版本已经具备；「候选」表示需要原型与试玩验证，不能当作已完成内容。
> 武器变种与双武器融合已有独立方案，本文只规定它与整体玩法的关系，不复制配方和逐级数值。

## 一、扩充目标

当前版本已经不缺基础系统，继续扩充的重点不是再加一批武器、敌人和数值卡，而是解决四个问题：

1. **房间缺少身份**：普通战斗房容易被记成「又一波怪」，需要可预告、可辨认的遭遇结构。
2. **构筑中段缺少转向**：拿到核心武器后，后续选择容易退化为线性增伤，需要行为变化和有限度的修正手段。
3. **敌人缺少组合关系**：单体行为已有差异，但不同敌人之间还应形成掩护、夹击、区域封锁等配合。
4. **资源缺少后续消费**：银币、重抽、跳过、商店已经成立，还要防止后期有钱无东西可买或永远只买同一项。

每轮扩充至少改善其中一项。只增加内容数量、不改变选择的条目不进入实施。

## 二、现有基础与不再重复建设的内容

| 已有基础 | 后续扩充的边界 |
|---|---|
| 三层地下城、房间推进、战斗房与特殊房混合 | 保留短房间节奏，不改成大地图生存 |
| 自动开火、移动与瞄准为主 | 不增加装填、主动技能栏或新的常驻操作键 |
| 11 种武器、4 个武器槽、5 级成长、宝箱进化 | 优先改行为和构筑关系，不先扩充武器总数 |
| 被动道具、升级三选一、重抽、跳过、放逐 | 优化候选质量，不再加一套同功能随机菜单 |
| 局内银币与商店、局外血晶 | 两种货币继续严格分离，不互相兑换 |
| 精英词缀与双词缀猎物 | 新遭遇复用词缀，不再创造第二套精英规则 |
| 流血、霜缚、汲取等状态 | 优先做状态间的条件联动，不堆更多同名增伤状态 |
| 深渊契约、受诅宝箱、深渊猎物 | 新风险选项必须提供不同决策，不能只是换一份数值 |
| 深渊阶梯与每日修饰 | 难度增加保持显式、可预知，不在战斗中暗中改规则 |
| 弹道亮芯、命中反馈、地面预警、同屏上限 | 所有新内容先满足可读性和性能预算 |

以下内容不再作为「新建议」重复提出：基础商店、重抽、跳过、放逐、单纯增伤进化、普通精英词缀、基础风险契约、基础限时猎物。

## 三、设计约束

### 3.1 操作与节奏

- 玩家需要做的仍是移动、瞄准、选择奖励和选择路线。
- 新目标尽量通过站位、靠近、远离、集火顺序完成，不要求额外按键。
- 战斗房仍以约 30 秒为基准；新事件与战斗并行，不把房间拖成长时间防守。
- 特殊房提供喘息和决策，不连续安排多个弹窗。

### 3.2 构筑

- 每个强化至少回答一个问题：改变攻击形状、目标优先级、站位、资源用途，还是风险收益。
- 纯伤害卡可以保留用于补差，但不能成为大多数升级的实际结果。
- 协同效应应来自已有行为的相互作用，不采用「凑齐两件就全屏增伤」的隐形套装。
- 强力效果必须伴随条件、空窗、站位要求或资源代价，避免无条件最优。

### 3.3 公平性

- 房间修饰、主要风险和奖励在进入前可见。
- 不用无法辨认的诅咒、未说明的负面效果或随机禁用核心武器制造难度。
- 新攻击不得从视野外无预警命中；地面危险不得被经验和特效完全遮住。
- 同一房间内锁定敌人强度规则，不根据玩家实时输出临时改变当前敌人的血量。

## 四、构筑扩充

### 4.1 武器成长：从数值爬坡改为行为分段

武器变种与融合按既有方案推进，整体玩法只补充以下约束：

- 普通升级负责逐步形成弹道、穿透、范围、持续、连锁等行为差异。
- 宝箱进化继续服务「单武器 + 对应被动」路线。
- 双武器融合服务「两条满级武器交汇」路线；两条路线互斥，避免同一武器连续叠多个终点。
- 融合的价值来自行为重组和槽位释放，不来自数十倍伤害。
- 卡片必须写出本次真正变化的字段；没有实际生效的攻速、弹道或范围不能出现在文案里。
- 新行为继续遵守房间内索敌、同屏数量、投射物上限和状态触发频率限制。

验收重点不是配方数量，而是玩家在第 2、3、4 级能说出武器发生了什么变化。

### 4.2 转折型被动：第一批候选

这批道具不增加新货币和新操作，每项只改变一条现有规则。先从 3 项做原型，验证后再扩到整批。

| 候选 | 行为变化 | 代价或限制 | 服务的构筑 |
|---|---|---|---|
| 处刑印记 | 持续命中同一精英或 Boss 时逐步叠加伤害 | 切换目标即清空；普通小怪无收益 | 单体、穿透、Boss 战 |
| 时滞齿轮 | 弹丸变大并增加穿透 | 弹速降低，不改变索敌射程 | 穿透、近距离弹幕 |
| 寒血反应 | 对带流血的霜缚目标造成一次小额破裂 | 每个目标有独立冷却，不能递归触发 | 状态联动 |
| 静默领域 | 近距离攻击获得额外效果范围 | 远距离攻击伤害降低 | 近身、毒雾、火舌 |
| 守财奴 | 房间结束时的未消费银币提供小幅临时护盾 | 进入商店后消失，不与永久护盾叠加 | 经济、防御 |
| 战场回收 | 每清理一定数量的投射物或召唤物返还少量银币 | 普通敌人不触发，设有每房上限 | 反召唤、经济 |
| 险境专注 | 被敌群包围时缩短攻击间隔 | 附近有友方安全空间时无效果，设触发上限 | 高压、近身 |
| 余震核心 | 范围攻击结束后留下一次延迟小爆发 | 直接命中伤害略降，延迟爆发不再次触发 | 毒雾、血爆、范围 |

实施时删掉收益表述含糊的项。不能产生可见行为差异、只让面板数字变大的候选不保留。

### 4.3 协同只描述规则，不设套装栏

武器和被动可以拥有「投射物、区域、状态、近身、连锁」等检索标签，用于卡片说明、图鉴和候选池控制。标签本身不提供 2 件、4 件套装加成。

推荐联动：

- 区域 + 状态：区域延长状态覆盖，状态触发有冷却，避免每次伤害都连锁。
- 穿透 + 减速：同一排敌人更容易被多次命中，代价是更依赖站位。
- 近身 + 防御：贴近敌人获得收益，但不能同时免疫近身风险。
- 连锁 + 单体标记：优先连接被标记目标，仍不能跳出房间。
- 经济 + 防御：保留银币换取有限保护，与立即消费形成取舍。

### 4.4 候选池质量

在现有重抽、跳过、放逐之上，只补轻量保护：

- 满级、已满槽、条件不可能满足的条目不得进入候选。
- 同一手三个选项不得全部是同一武器或完全相同的纯数值方向。
- 连续多次没有出现可强化已有构筑的选项时，提高相关条目的权重；只提高权重，不直接指定成品。
- 风险道具与普通补给不在同一手同时出现，避免玩家误以为三张都是同级增益。
- 所有保底都可解释、可测试，不在后台根据胜率暗改掉落。

## 五、敌人组合与遭遇导演

### 5.1 从单体 AI 扩到小队关系

第一批不制作新敌人，用现有行为组合出不同解题顺序。每个模板只设置一个主要威胁，其余单位负责配合。

| 遭遇模板 | 组合方式 | 玩家需要做的事 | 奖励倾向 |
|---|---|---|---|
| 盾墙推进 | 高血近战在前，远程在后方同步推进 | 穿过缝隙、利用穿透或绕侧 | 经验 |
| 交叉夹击 | 两侧快速单位分批进入，中央保留普通追击 | 先清一侧，避免被围到墙边 | 银币 |
| 召唤仪式 | 召唤单位保持后排，前排阻挡路线 | 优先击杀召唤者，而非无限清小兵 | 经验与补给 |
| 爆破链 | 自爆单位与慢速近战混编，爆炸有清晰预警 | 拉开间距，诱导爆炸打乱敌群 | 银币 |
| 护卫精英 | 一个精英带少量护卫，护卫不重复精英词缀 | 决定先削护卫还是强杀精英 | 词缀对应奖励 |
| 远程封锁 | 远程单位分占两个方向，近战队压缩安全区 | 先突破一个火力方向 | 经验 |

### 5.2 导演规则

- 使用「遭遇预算」选择小队，而不是每次独立随机所有敌人。
- 同一房的敌人总数、精英数、召唤数和投射物数继续受硬上限约束。
- 第 1 层只出现单核心组合；第 2 层允许两种组合衔接；第 3 层才允许精英与复杂组合同时出现。
- 同一模板不连续出现两次；连续两房不得重复使用相同的主要威胁。
- 召唤物、分裂体和事件援军共享房间预算，特殊事件不能绕过性能限制。
- 玩家清掉核心单位后，组合应明显失去威胁，形成「解开了」的反馈。

### 5.3 后续新敌人的准入标准

只有组合仍无法提供以下行为时，才考虑新敌人：

- 为周围敌人提供可打断的增益；
- 改变一块区域的通行成本；
- 偷取或搬运地面资源，形成短时追击目标；
- 将玩家的站位习惯转化为可预见的反制。

新敌人先复用现有轮廓、颜色和动作组合做灰盒，不为一个只出现一次的特殊机制单独扩整套资产。

## 六、房间变体与路线选择

### 6.1 先做预告，再做分支

第一步只在传送门和 HUD 显示下一房的「类型 + 主要修饰 + 奖励倾向」。即使暂时没有分支，玩家也能决定是否先消费、治疗或保留资源。

第二步再在少数楼层节点提供两个出口：

- 普通房：标准敌人组合与奖励；
- 凶险房：一个明确修饰，奖励提高；
- 出口不出现完全未知的惩罚，不用纯文字谜语代替信息。

分支只改变下一房，不建立复杂大地图，不改变三层主结构。

### 6.2 普通战斗房变体候选

变体直接复用现有战斗房，不新增房间类型。每层最多遇到一个主要变体。

| 变体 | 规则 | 玩家收益 | 主要风险 |
|---|---|---|---|
| 血潮 | 敌人分批更密集，单体血量略低 | 更多经验 | 被持续包围 |
| 重甲巡行 | 数量减少，前排更耐打，后排仍脆弱 | 更多银币 | 单体输出不足 |
| 交叉火力 | 远程从两个方向出现，近战数量下降 | 额外经验 | 安全区被压缩 |
| 不稳定地脉 | 周期性出现预警爆发，玩家与敌人都会受伤 | 完成房间获得额外银币 | 站位被倒计时强迫改变 |
| 猎手走廊 | 快速单位分批冲锋，普通追击减少 | 击杀快速单位掉落提高 | 被连续冲锋逼入角落 |
| 寂静前厅 | 小规模战斗，无额外事件 | 少量恢复或普通补给 | 奖励较低，消耗一次成长机会 |

地脉类环境伤害必须能伤敌，让它成为可以利用的规则，而不是单纯多一个陷阱。

### 6.3 局内目标事件扩充

现有猎物与守宝事件保留。后续候选只在验证不同玩法时加入：

| 候选事件 | 目标 | 失败结果 | 不采用的做法 |
|---|---|---|---|
| 血巢 | 在限时内摧毁持续产怪的核心 | 核心消失，无奖励 | 无限刷怪供玩家 farm |
| 逃匿魔 | 追击高机动目标，利用走位封堵 | 目标逃走，无奖励 | 随机瞬移到无法到达的位置 |
| 双封印 | 依次靠近两个封印并保持短暂停留 | 进度保留一部分，房间结束后关闭 | 要求额外互动键 |
| 悬赏决斗 | 接受后只强化一个可见目标 | 可拒绝，失败无额外惩罚 | 全房敌人无条件暴增 |

所有事件继续遵守：可拒绝或失败不致命、离开房间即取消、奖励只结算一次、事件不占独立新房间类型。

## 七、局内经济扩充

### 7.1 商店决策

在现有购买和重抽基础上，按以下顺序补齐：

1. **价格曲线**：同一商店连续重抽逐步提高价格，进入下一商店重置，避免无限刷池。
2. **保留一项**：可锁定一个未购买商品到下一商店；只能锁一项，购买或替换后解除。
3. **恢复与强化竞争**：治疗始终有稳定但有限的价格，不让残血玩家只能依赖随机掉落。
4. **稀有服务**：每层最多出现一次重铸或拆解，服务与商品争夺同一笔银币。

### 7.2 重铸与拆解候选

这是构筑纠错的有限工具，不是免费洗掉随机成本。

- 重铸只允许替换尚未进化、尚未融合的武器。
- 结果从少量可见候选中选择，不完全随机；替换后降低一级或收取明显费用。
- 每层最多一次，不能反复把同一武器刷成指定终点。
- 拆解只移除一级被动并返还少量银币，不产生额外升级次数。
- 涉及进化条件时，界面必须提前说明移除后会使哪条进化失效。

若试玩表明玩家总是保留服务费用、从不购买普通商品，应先调整价格和商品质量，不继续加新货币。

### 7.3 经济边界

- 跳过、事件、风险房的奖励使用定额或清晰的房间倍率，不与多个掉落倍率无限连乘。
- 任何「杀敌返银币」「保留银币获盾」都设每房或每层上限。
- 放逐继续只影响升级池，不顺便控制商店池。
- 局内银币不带出局，局外血晶不反哺单局购买。
- 商店关闭后恢复世界状态时，不得让敌人或地面危险提前行动。

## 八、Boss 与精英战的扩充

### 8.1 Boss 战优先增加可读的阶段关系

现有三形态继续作为基础，后续不优先增加 Boss 血量或新弹幕数量，而是补以下结构：

- 每阶段一个主要行为主题，颜色、动作和音效随阶段统一变化。
- 大招前有稳定预警，大招后有明确收招空窗，形成「躲避 → 反击」循环。
- 召唤阶段限制援军数量，击杀召唤物不能直接跳过全部 Boss 机制。
- 阶段切换清理不再适用的危险区域，避免上一阶段残留与转场叠加。
- 狂暴只改变已展示过的规则组合，不在残血时突然出现无预警新伤害。

### 8.2 破势窗口候选

用轻量「破势」替代复杂弱点部位系统：

- 玩家躲过特定重击或在收招期持续命中，积累破势。
- 破势充满后造成短暂硬直，不永久眩晕，也不能连锁锁定 Boss。
- 每个阶段最多触发一次，UI 只显示当前阶段进度。
- 不能破势的招式仍可通过正常走位处理，避免所有攻击都变成同一种答题。

该机制先做单个 Boss 原型；若只是额外一条自动增长的眩晕条，就不保留。

### 8.3 精英与 Boss 的边界

- 精英词缀提供短房间内的局部变化，Boss 使用固定且可学习的阶段机制。
- Boss 不随机叠加普通精英词缀。
- 双词缀只服务特殊猎物和高层深渊，不继续向普通精英普及。
- 新 Boss 奖励优先解锁新玩法或侧向选择，不用永久高数值强迫反复刷。

## 九、难度、局外成长与重玩

### 9.1 难度继续显式化

- 普通三层的敌人强度在进房时确定，房中不做隐藏难度追踪。
- 深渊阶梯继续承载数值与规则递增，新增词缀必须在进入下一轮前列出。
- 新难度修饰优先改变敌人组合、远程比例、资源稀缺和事件频率，不只加血。
- 每日修饰与普通局共用规则，不为单日增加一次性的例外逻辑。
- 提供固定种子便于复现，但不把排行榜或联网服务作为玩法前置条件。

### 9.2 局外解锁以横向内容为主

已有永久升级保留；新增解锁尽量采用：

- 新初始武器或角色侧向机制；
- 新房间变体、事件和转折型被动进入池；
- 新深渊修饰和可自选的挑战条件；
- 图鉴、行为说明和构筑记录。

解锁条件必须写清楚，并能在结算界面看到进度。不要求是哪个隐藏成就、不靠反复刷同一个低难度房间。

### 9.3 结算与复盘

扩充系统后，结算至少回答：

- 本局主要武器、被动、进化或融合路线是什么；
- 哪一房、哪种敌人或哪种攻击造成最后伤害；
- 哪个武器和状态贡献了主要输出；
- 银币主要花在哪里，是否留有大量未消费资源；
- 下一项可解锁内容还差多少。

复盘数据用于理解选择，不用评分把某种构筑宣布为唯一正确答案。

## 十、表现与信息可读性

### 10.1 新机制的视觉预算

- 敌人危险：红色或橙红色实线、填充预警。
- 可利用环境：与敌方危险不同的形状，不只换颜色。
- 玩家区域：保留现有武器色系，但降低地面覆盖的不透明度。
- 房间修饰：入口横幅一次 + HUD 简短常驻，不重复弹大字。
- 破势、状态联动和事件目标分别使用不同位置，不能全堆在敌人头顶。

### 10.2 战斗信息优先级

1. 即将造成伤害的预警；
2. 玩家、精英和 Boss 的位置；
3. 当前事件目标与出口；
4. 玩家攻击、经验和掉落；
5. 装饰粒子与环境效果。

性能不足时从第 5 层开始削减，不降低危险预警的清晰度。

### 10.3 音频与文案

- 新敌人复用现有攻击和受击音色，只有新的危险行为才增加提示音。
- 同类连续命中继续合并播放，避免联动机制造成音频爆炸。
- 卡片写行为与条件，例如「近距离范围扩大，远距离伤害降低」，不写「大幅增强」「史诗级」等空描述。
- 房间预告同时写风险与收益，不能只写奖励倍率。

## 十一、数据与实现边界

后续实现仍复用现有架构：

- 武器、被动、敌人、词缀、房间变体各自保留单一数据源。
- 遭遇模板只描述敌人角色、数量预算、入场方向和奖励倾向，不复制一套伤害公式。
- 房间变体修改遭遇生成参数，不直接逐帧扫描并修改所有敌人。
- 状态联动使用明确事件和单目标冷却，禁止 A 触发 B、B 再无条件触发 A。
- 所有限时器、持续效果和事件在换房、重开、回主菜单时统一清理。
- 新随机结果可由种子复现；表现随机与玩法随机分流。
- 新系统先使用现有美术和音频组合验证，不在原型阶段引入资产包或外部运行依赖。

## 十二、实施顺序

### A. 当前优先：武器成长收束

- 完成武器变种与融合方案的验证。
- 先保证升级文案、实际字段、融合互斥和槽位行为一致。
- 不在同一轮加入转折型被动和新房间变体，避免无法判断平衡变化来自哪里。

### B. 下一内容包：遭遇与房间身份

- 3 个遭遇模板：盾墙推进、交叉夹击、召唤仪式。
- 2 个房间变体：血潮、交叉火力。
- 下一房预告，不加分支地图。
- 验证组合被解开后是否明显降压，以及同屏预算是否稳定。

### C. 构筑与经济包

- 从转折型被动中选 3 个原型。
- 加入同店重抽涨价与单项保留。
- 只选择一个有限纠错服务做原型：重铸或拆解，不同时上。
- 根据购买率和剩余银币决定是否继续扩经济内容。

### D. 长期内容包

- 房间双出口、额外目标事件、破势窗口和更多 Boss。
- 横向解锁与完整战斗复盘。
- 只有前面的系统证明有选择价值后才扩数量。

每包只引入一个主要新规则；出现平衡问题时先停用该规则，不同时改整张数值表掩盖原因。

## 十三、验收标准

### 13.1 玩法验收

- 玩家看下一房预告，能说出主要风险和奖励倾向。
- 三个遭遇模板即使隐藏名称，也能通过敌人位置和推进方式区分。
- 转折型被动会改变站位、目标选择或资源消费，而不只是提高结算 DPS。
- 同一构筑连续三局仍有可变化的选择；不同构筑不会都收敛到同一个商店服务。
- 风险房可以拒绝，事件失败不会附带未说明的惩罚。
- Boss 的主要伤害都能通过已展示的预警和走位处理。

### 13.2 稳定性验收

- 升级、融合、进化、重铸之间没有重复占用槽位或重复结算奖励。
- 召唤、分裂、连锁、状态联动均不能绕过同屏与触发频率上限。
- 换房和重开后无残留事件、持续伤害、计时器或房间修饰。
- 固定种子可复现同一房间的模板、候选和奖励。
- 大量经验、掉落与特效同时出现时，危险预警仍清楚。
- 商店、升级、事件和暂停界面不会让世界提前恢复。

### 13.3 需要记录的数据

- 各房间受伤、死亡、耗时和退出原因；
- 各遭遇模板的完成率与事件成功率；
- 武器选择、升级、进化、融合和重铸路径；
- 商店购买、重抽、保留和房间结束余额；
- 转折型被动的选取率与更换构筑比例；
- 同屏敌人、投射物、掉落物的峰值与对象池扩容次数。

数据用于发现无选择价值的条目，不用于在战斗中偷偷调整难度。

## 十四、明确不做

- 不增加装填、弹匣、主动技能键、复杂道具栏或武器耐久。
- 不做需要背诵的大量固定配方；新配方必须能改变行为且可预览。
- 不做套装件数奖励、稀有度颜色膨胀或多层品质升级。
- 不做未鉴定诅咒、随机禁用核心构筑、无预告的必杀。
- 不做无限敌人、无限分裂、无限状态连锁或事件奖励循环。
- 不把现有房间制改成无缝大地图，也不先做复杂分支地图界面。
- 不用永久高数值解锁掩盖局内构筑不足。
- 不通过新增货币、菜单和弹窗制造「内容丰富」的假象。
- 不复制外部代码、资产、数据结构或仓库依赖。

## 十五、最终判断标准

一项扩充只有同时满足以下条件才保留：

1. 玩家能在游戏内理解它，而不是必须读说明文档。
2. 它改变了至少一个实际选择，而不是只增加一个数值。
3. 它与现有系统复用规则，不制造第二套平行机制。
4. 它的风险、收益和失败结果都可预期。
5. 它在三层一局的时长内有出场机会，不是极少数局才能看到的装饰内容。
6. 它通过性能、换房清理、暂停恢复和固定种子测试。

如果一项内容只能证明「数量更多」，不能证明「选择更多」，就删除或继续留在候选，不进入正式版本。
